جمع البيانات

لا يقوم التطبيق بجمع أو تخزين أو مشاركة أي بيانات شخصية للمستخدمين.

تسجيل الدخول

لا يتطلب التطبيق إنشاء حساب أو تسجيل دخول.

الموقع الجغرافي

لا يقوم التطبيق بطلب أو استخدام أو تتبع موقع المستخدم.

التحليلات والإعلانات

لا يستخدم التطبيق أي أدوات تحليل أو تتبع أو إعلانات أو خدمات طرف ثالث.

محتوى التطبيق

التواصل
